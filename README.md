# 📻 Aurora FM

一个界面美观的免费电台客户端，数据来自开源电台目录 [Radio Browser](https://www.radio-browser.info/)（全球 5 万+ 免费电台，无需任何 API Key）。

## 功能

- 🔍 **搜索电台**：按名称搜索全球电台，也支持热门 / 华语 / 音乐 / 新闻分类浏览
- ⏮️ **上一台 / 下一台**：在当前列表中快速切换（支持键盘 ← → 方向键）
- ▶️ **播放 / 暂停**（空格键）
- 🔊 **音量调节 / 静音**（↑ ↓ 方向键微调）
- 🔁 **自动轮播**：可设置 2 / 5 / 10 分钟自动切换下一台电台
- ⭐ **收藏电台**：收藏结果保存在浏览器本地（localStorage）
- 🎨 玻璃拟态深色 UI、悬浮唱片、均衡器动画

## 运行

纯静态项目，无需安装依赖，任选一种方式启动本地服务：

```bash
# Python
python -m http.server 8000

# 或 Node.js
npx serve .
```

然后浏览器打开 <http://localhost:8000>

> 注意：需要通过 HTTP 服务访问（而非直接双击打开文件），且部分电台流依赖其所在地区的网络可达性；个别电台若连接失败会自动跳到下一台。
